# Статусы доказательств

Используй один из статусов для каждого существенного результата.

| Код | Отображение | Когда применять |
|---|---|---|
| `primary_verified` | Подтверждено первичным источником | Реестр или официальный ответ фактически проверен в текущей сессии |
| `document_verified` | Подтверждено документом | Сведения следуют из открытого и читаемого документа пользователя |
| `secondary_signal` | Вторичный сигнал | Агрегатор или публикация; первоисточник не проверен |
| `conflict` | Расхождение | Два источника дают несовместимые значения на одну дату или за один отчётный период |
| `not_confirmed` | Не подтверждено | Утверждение встречается, но достаточного доказательства нет |
| `not_checked` | Не проверялось | Проверка не выполнялась |
| `source_unavailable` | Источник недоступен | Попытка выполнена, но источник технически недоступен |
| `not_found` | Не выявлено | Конкретный источник и период проверены, совпадений нет |

`primary_verified` применяй только после прямого обращения к актуальному первичному источнику в текущей сессии. Документ пользователя, даже если это официальная выписка или отчётность, получает `document_verified`; в тексте укажи орган, дату документа и способ подтверждения подписи, если он проверялся.

Различающиеся сведения на разные даты показывай как хронологию. Например, ограничение по счёту на 01.03 и отсутствие ограничения на 01.06 не являются `conflict`, если оба события могут последовательно существовать.

В PDF показывай только русское отображение статуса. Технические коды допустимы в JSON, но не в готовом отчёте.

## Достаточность доказательств

- **Высокая:** личность совпала; ключевые выводы подтверждены первичными источниками; критических пробелов нет.
- **Средняя:** личность совпала; основные документы проверены; часть выводов основана на вторичных данных или один критический источник недоступен. Если финансовый анализ основан только на агрегаторе, достаточность не может быть выше средней.
- **Низкая:** несколько ключевых областей не подтверждены, данные противоречат друг другу либо параметры сделки неизвестны и существенно влияют на решение.

Достаточность не заменяет риск-балл. Низкая достаточность запрещает решение «Допустить» без условий.
